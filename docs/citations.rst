This plug-in evaluates the likelihoods with ``RooFit`` and ``RooStats``, and compiles datacards with ``combine``;
please also cite the tools used by the backend you rely on:

* ``RooFit``: W. Verkerke and D. Kirkby, :xref:`physics/0306116`
* ``RooStats``: L. Moneta et al., :xref:`1009.1003`
* CMS Combine: CMS Collaboration, :xref:`2404.06614`
* asymptotic formulae for the test statistics: G. Cowan et al., :xref:`1007.1727`
